
# SmartCampus Complaint Management System

A web-based complaint management system built using Python, Flask, and SQLite.

## Live Demo

[Open SmartCampus Complaint System](https://smartcampus-complaint.onrender.com)

## Features
- Submit campus complaints
- Track complaint status
- Admin dashboard
- Update complaint status

## Technologies
- Python
- Flask
- SQLite
- HTML
- CSS
