# 🎓 SmartCampusComplaint

### 🏫 A Smart Way to Manage Campus Complaints

SmartCampusComplaint is a web-based complaint management system designed to help students submit campus-related complaints online and make complaint management easier for administrators.

---

## ✨ Features

- 📝 **Submit Complaints** — Students can submit complaints online.
- 🔎 **Track Complaints** — Check complaint status using the available tracking feature.
- 🛠️ **Admin Dashboard** — Administrators can manage submitted complaints.
- 🌐 **Online Access** — Access the application through a web browser.
- 📱 **Simple Interface** — Easy-to-use and user-friendly design.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** Python, Flask
- **Database:** SQLite
- **Version Control:** Git & GitHub


## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Dhanashri-Chaudhari07/SmartCampusComplaint.git
   ```

2. Open the project folder:

   ```bash
   cd SmartCampusComplaint
   ```

3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open your browser and visit:

   ```text
   http://127.0.0.1:5000
   ```
